# MAY.SHOP FINAL

نسخه اصلاح‌شده فروشگاه:
- نمایش عکس محصول با تصویر جایگزین در صورت خطا
- افزودن به سبد خرید
- افزایش/کاهش/حذف کالا از سبد
- جستجو و دسته‌بندی
- افزودن و ویرایش و حذف محصول در مدیریت
- انتخاب عکس از گوشی و کم‌حجم‌سازی خودکار
- ثبت سفارش و باز کردن واتساپ با متن آماده سفارش
- فایل `config.js` برای شماره واتساپ فروشنده

## تنظیم شماره واتساپ
در `config.js` مقدار `whatsapp` را با شماره فروشنده، بدون + و بدون صفر اول وارد کنید.
مثال:
`whatsapp: "989121234567"`

سپس کل محتویات این پوشه را روی Cloudflare Pages آپلود کنید.

نکته: چون سایت استاتیک است، محصولات بخش مدیریت در localStorage همان مرورگر ذخیره می‌شوند. سفارش مشتری از طریق واتساپ ارسال می‌شود و به localStorage مشتری وابسته نیست.
